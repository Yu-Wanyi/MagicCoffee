# MagicCoffee ☕️

MagicCoffee 是一個依照 [Figma 設計稿](https://www.figma.com/community/file/1032782759644907635) 實作的 iOS App，主要目的是練習使用 **UIKit** 在 Xcode 上完成設計轉換與畫面還原。  

---

## 📱 專案簡介
- 參考 Figma 社群設計稿進行 UI 畫面實作  
- 著重在 **UIKit** 開發與設計還原  
- 適合作為 iOS UI 練習專案  

---

## 🛠 使用技術
- **Swift**  
- **UIKit**  
- **Xcode**  

---

## ✨ 主要功能
- 還原設計稿中的 **首頁 / 商品列表 / 商品詳情頁**  
- 基本的 **導航功能與畫面切換**  
- 支援 **iPhone 模擬器與實機**
